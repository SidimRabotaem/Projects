Реализация собственного динамического контейнера Vector на C++, аналогичного std::vector.

Проект демонстрирует работу с ручным управлением памятью и временем жизни объектов: выделение сырой памяти, конструирование и уничтожение объектов через placement new, реаллокацию, copy/move-семантику и обработку исключений.
