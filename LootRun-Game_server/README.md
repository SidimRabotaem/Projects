Game Server — сервер многопользовательской игры

Сервер управляет игровыми картами, состоянием игроков и игровой логикой, обрабатывает действия пользователей и взаимодействует с клиентом через HTTP API.

Реализованные возможности:

Игровая модель: карты с дорогами, зданиями и базами; движение персонажей с учётом геометрии карты.

Игровая механика: генерация потерянных предметов, обнаружение столкновений, сбор и сдача предметов на базу, перенос предметов в рюкзаке и начисление очков.

Игровое время: автоматическое и ручное обновление состояния игры, обработка игровых событий и завершение игровых сессий при бездействии игроков.

HTTP API: вход в игру, получение списка карт и их описаний, управление движением персонажей, получение игрового состояния и таблицы рекордов.

Сохранение состояния: сериализация и восстановление игрового состояния при перезапуске сервера, периодическое сохранение и корректное завершение работы.

Сетевая инфраструктура: асинхронная обработка HTTP-запросов, многопоточная работа сервера, валидация запросов и обработка ошибок.

Надёжность и сопровождение: структурированное логирование, конфигурация через JSON и параметры командной строки, модульное тестирование игровой логики.
