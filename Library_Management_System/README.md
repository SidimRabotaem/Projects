Консольное приложение для управления библиотекой книг на C++ с использованием PostgreSQL.

Реализованы:

* CRUD для авторов и книг;
* добавление, редактирование и удаление тегов;
* транзакционная работа с PostgreSQL;
* сортировка и поиск книг;
* UUID для идентификации книг и авторов;
* модульные тесты с Catch2.
