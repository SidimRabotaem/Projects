Async HTTP Server

Асинхронный многопоточный HTTP-сервер на C++ с поддержкой GET, HEAD и обработкой неподдерживаемых HTTP-методов.

Реализованы асинхронные приём соединений и обработка HTTP-запросов с использованием Boost.Asio и Boost.Beast, корректное формирование HTTP-заголовков и обработка сигналов SIGINT/SIGTERM.
