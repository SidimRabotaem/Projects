C++-сервис для работы с данными городского общественного транспорта. Приложение загружает транспортную сеть из JSON, хранит информацию об остановках и автобусных маршрутах и обрабатывает запросы на построение оптимальных маршрутов.

Транспортная сеть преобразуется во взвешенный ориентированный граф, после чего с помощью алгоритма поиска кратчайшего пути рассчитывается маршрут с минимальным временем поездки, включая ожидание автобуса и пересадки.

В проекте реализованы:

работа с JSON;
модель остановок и автобусных маршрутов;
построение транспортного графа;
поиск кратчайшего пути;
расчёт времени маршрута и пересадок;
поддержка направленных расстояний и кольцевых маршрутов;
JSON API для запросов и ответов.
