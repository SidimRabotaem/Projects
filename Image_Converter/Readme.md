Расширение библиотеки ImgLib поддержкой формата BMP.

Реализованы чтение и запись 24-bit BMP, работа с бинарными заголовками, RGB-данными и выравниванием строк. Для эффективного ввода-вывода используется буферизация построчного чтения и записи.

Добавлена интеграция BMP в существующий конвертер изображений с поддержкой BMP, JPEG и PPM.
